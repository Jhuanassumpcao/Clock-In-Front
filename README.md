# Clock-In-Front

[Deploy do Projeto](https://clock-in-front.vercel.app/login)

Este projeto utiliza as seguintes tecnologias:

- Docker
- npm
- React

Além disso, segui os princípios SOLID para garantir um código mais robusto e manutenível.

## Como rodar o projeto

Para rodar o projeto, você pode usar uma das seguintes opções:

### Usando Docker Compose

```sh
docker-compose up
```

### Usando npm

```sh
npm run dev
```

## Deploy

O deploy deste projeto foi realizado no Vercel
